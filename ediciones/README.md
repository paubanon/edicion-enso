# Ediciones

Aquí trabaja Claude: una carpeta por reel (`ediciones/Pancake/`, …), con el mismo nombre que su carpeta en `tomas/`.

| Subcarpeta | Qué hay |
|---|---|
| `edit/` | Transcripción, corte, storyboard (`storyboard.html`) y notas de traspaso entre sesiones (`handoff.md`) |
| `public/` | Material que usa Remotion: el corte, tu silueta recortada, B-roll y objetos |
| `src/` | El código del reel |
| `out/` | Borradores, renders y capturas de control de calidad |

Puedes borrar la carpeta de un reel para liberar espacio: tus tomas siguen en `tomas/` y el vídeo entregado en `finales/`. Lo único que se pierde es la posibilidad de retocar esa edición sin rehacerla.

Nada de esta carpeta se sube a GitHub, salvo este README.
