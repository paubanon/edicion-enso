# Referencias

Deja aquí **reels de referencia visual**: vídeos cuyo estilo de edición te guste (tipografía, gráficos, ritmo, color). Descárgalos de Instagram en `.mp4` y ponles cualquier nombre.

Cuando haya referencias nuevas, Claude las analiza al empezar el siguiente reel y te propone qué tomar de ellas. Lo que se decida queda escrito en `.claude/skills/reel-editor/STYLE.md`.

Los vídeos de esta carpeta no se suben a GitHub (son de otras personas).
